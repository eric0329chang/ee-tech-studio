## 檔案

```

css/style.css   ← 顏色 / 字體 / 間距都在最上面的 :root

```

## 設計原則（Apple 式）

- **亮色、單一強調色（冰藍）**：背景 `#fbfbfd` 與 `#f5f5f7` 交錯、字 `#1d1d1f`。冰藍太淺，放在白底上當文字看不清楚（對比 1.5:1），
  所以拆成兩階，都在 `css/style.css` 最上面：`--ice`（冰藍本色，只用在填色：按鈕底、光暈、3D 零件）、
  `--ice-ink`（同色相深一階，白底上的文字 / 連結 / 細線，對比 5.3:1）。錯誤訊息保留紅色（功能性警告色）。
  3D 機械的冰藍零件在 `js/machine.js` 的 `M.ice` / `M.iceDeep`。

- **沒有人為的等待**：不放載入倒數；字型好了主標就直接出現。
- **材質**：導覽列、選單、卡片是半透明玻璃（`backdrop-filter`），底邊 / 上緣一條細亮線；越大的面陰影越深。
  卡片用 Apple 式連續圓角（`corner-shape: squircle`，不支援的瀏覽器退回一般圓角）；高解析螢幕的分隔線是 0.5px 細線（`--hairline`）；焦點環較粗、半透明。
  使用者在系統裡開了「降低透明度」或「提高對比」，會自動換成實色（見 css 最下面）。
- **字體**：系統字體優先（Apple 裝置是 SF Pro、中文是蘋方），其他平台用 Inter（載入有光學尺寸軸的版本，字大字小自動換字形）。
  字距、行高都是 token（`--track-*`、`--lh-*`，在 `css/style.css` 最上面），隨字級走：大字收緊、小字放寬、行高與字級成反比。
  **中文是方塊字，標題字距只收到 -0.02em**（-0.045em 會讓字黏在一起）；標題字重 600。
  標題 `text-wrap: balance`、內文 `text-wrap: pretty`，不會剩孤字；`line-break: strict` 讓中文標點不出現在行首。
  字級全部用 `rem`：使用者把系統 / 瀏覽器文字調大，版面會跟著放大（Dynamic Type）；最小字級 12px。
- **動態用彈簧**：`css/style.css` 的 `--spring`（阻尼 1.0，沒有彈跳）和 `--bounce`（阻尼 0.8）是取樣成 CSS `linear()` 的彈簧曲線；
  按下立刻回饋（`:active` 縮放），放開用彈簧彈回。選單開關是 CSS 轉場，轉到一半再點會從目前的位置反向。
- **直接操作**：3D 機械可以用滑鼠按住轉動——貼著游標 1:1 跟隨，超過範圍有橡皮筋阻力，放開時帶著放手的速度、用彈簧回到原位；
  回彈到一半抓住它可以立刻接手。手機的手指留給捲動，不處理拖曳。
- **減少動態**：系統設定「減少動態效果」時不放捲動動畫與 3D，改成一般頁面，只留淡入淡出。

## 用到的函式庫（都走 CDN）

- GSAP 3.15（ScrollTrigger、SplitText）：捲動敘事、文字進場
- Lenis 1.3：平滑捲動
- Three.js 0.186：3D（網址在 index.html 的 importmap）

GSAP 載不到、或使用者在系統設定裡關閉動畫效果時，網站會變成一般的長頁面，內容全部看得到。
3D 在關閉動效、省流量模式、不支援 WebGL 時不顯示；要查 3D 狀態可以在開發者工具看 `<html data-three="…">`。

## 更新網站時

1. 改完推到 GitHub 的 `main`，Pages 一兩分鐘內會更新。
2. `index.html` 裡 CSS / JS 網址後面都有 `?v=版本號`。改了 css 或 js 之後，把這些 `?v=` 一起換成新的數字（例如當下的日期時間），訪客的瀏覽器才會抓新檔案，不會卡在快取的舊版。

## 本機預覽

```bash
python -m http.server 5500
```

然後開 `http://localhost:5500`。

## 聯絡表單（FormSubmit）

表單透過 FormSubmit（formsubmit.co，免費、不用註冊）直接寄到 `ee.techww@gmail.com`。

1. **第一次啟用**：上線後自己送出一次表單，到 ee.techww@gmail.com 點 FormSubmit 寄來的「Activate Form」連結。開通前送出的那筆不會轉寄。
2. 之後每筆詢問都會是一封表格格式的信，主旨「[網站詢問] 類型－稱呼」。
3. 收件信箱在 `js/main.js` 的 `TO` 和 `index.html` 表單的 `action`。
